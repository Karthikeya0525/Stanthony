# 🌍 St. Anthony's High School – El Niño Educational Explorer

An interactive educational website developed for **St. Anthony's High School – Lillian Block, Telangana**, to help students and parents understand the El Niño phenomenon and its potential effects on weather, rainfall, agriculture, and water resources.

## 🚀 Project Overview

This project provides an engaging, multilingual learning experience through educational videos, interactive visualizations, historical climate information, and district-level exploration of Telangana.

The website is designed to be accessible through a QR code, making it easy for students and parents to explore using their smartphones.

## ✨ Features

- **Multilingual Support:** Educational content in English, Telugu, and Hindi.
- **Featured Video:** Dedicated educational video section.
- **Video Library:** Curated educational videos for different languages.
- **El Niño Introduction:** Simplified explanations and important facts.
- **Historical Timeline:** Explore major El Niño events from 1982–83 to 2023–24.
- **Interactive Telangana Explorer:** Explore different topics, including agriculture, water resources, Hyderabad, and weather.
- **District Explorer:** Select Telangana districts to view relevant information.
- **Weather Dashboard:** Planned integration of live weather observations, rainfall information, and official weather warnings.

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Karthikeya0525/Stanthony.git
```

### 2. Navigate to the project

```bash
cd Stanthony
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```

The production-ready files will be generated inside the `dist` directory.

## 🌐 Deployment

The project is intended to be deployed using [Vercel](https://vercel.com/).
